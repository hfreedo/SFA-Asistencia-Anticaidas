# Autoría

SFA Asistencia es un proyecto educativo desarrollado para la demostración de un
sistema de alerta ante caídas mediante un dispositivo wearable basado en
Arduino y una interfaz local de monitoreo.

Se publican el código fuente y el firmware del estado actual para consulta y
estudio. Su disponibilidad no implica cesión de autoría ni una licencia de
software libre. Las condiciones existentes del ejecutable se mantienen; los
permisos adicionales de modificación, explotación o redistribución deben
acordarse con el autor. Los datos personales y archivos privados no se publican.
